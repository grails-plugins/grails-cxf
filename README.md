🧩 Grails CXF Plugin
=====================

A Grails plugin that brings easy exposure of service and endpoint classes as
[Apache CXF](https://cxf.apache.org/) SOAP Services to Grails.

## Installation

Add the following to your `build.gradle` file:

```groovy
implementation 'org.grails.plugins:cxf:5.0.0-RC1'
```

The full user guide, including basic usage, custom interceptors, servlet mapping, and the
annotation reference, can be found here: 📚 [Documentation]

[Documentation]: https://grails-plugins.github.io/grails-cxf/
